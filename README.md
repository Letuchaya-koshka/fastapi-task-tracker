# fastapi-task-tracker

Учебный REST API для управления списком задач, построенный на FastAPI и SQLite. Проект реализует базовые CRUD-операции, валидацию данных через Pydantic и интерактивную документацию Swagger.

## Что здесь будет

- REST API на FastAPI для управления задачами
- Работа с базой данных

- FastAPI
